# 中国語センテンスノート

日本語の例文を自然な中国語に訳して、スマホで復習するための学習アプリです。

[中国語センテンスノートを開く](https://yuu-abc.github.io/chinese-sentence-notebook/)

## カードを作る

1. 「日本語から作る」で覚えたい文を入力し、ChatGPT用プロンプトを作ってコピーします。複数の文は１行に１文ずつ入力します。
2. プロンプトをChatGPTに送り、返ってきた回答をコピーします。
3. アプリの「貼り付けて取り込む」で回答を貼り付け、「取り込み内容を確認」を押します。
4. 中国語・ピンイン・日本語訳・単語・文法を確認し、必要に応じて修正してから「カードを登録」を押します。中国語だけの１行も登録できます。

## カード一覧で復習する

- 最初は全カードが閉じていて、中国語と日本語訳を短く表示します。カードをタップすると、ピンイン・単語・文法・メモが開きます。
- 開いたカードをもう一度タップすると閉じます。別のカードを開くと、前のカードが閉じます。
- 「発音」はカードを閉じたまま使えます。中国語の読み上げはブラウザや端末の音声機能を使います。
- 「日本語訳を隠す」をオンにすると、閉じたカードでは訳が隠れます。中国語を見て意味を思い出してから、カードを開いて答えを確認できます。
- 検索、タグ、お気に入りでカードを絞り込めます。

## バックアップ

カードは、使用した端末のブラウザに保存されます。端末やブラウザを変えるときは、「カード一覧」→「バックアップ」からファイルを書き出し、新しい端末でそのファイルを選んでカードを追加できます。
